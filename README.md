# Калькулятор м²

Отдельная мобильная PWA-версия калькулятора для iPhone.

Этот репозиторий не содержит кода для Bitrix24, Cloudflare или интеграционных файлов.

Возможности:
- ввод готовой площади;
- режим высота × ширина;
- несколько размеров с общей площадью;
- динамический список товаров;
- добавление и удаление товаров;
- сворачиваемое управление товарами и ценами;
- локальное сохранение данных;
- офлайн-работа после первого открытия.
